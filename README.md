# Jarvis app pages

Static pages for the Jarvis iOS app: privacy policy and support, in German and English, served
with GitHub Pages. Plain HTML and one stylesheet; no build step, no scripts, no cookies, no
external resources.

- `/privacy/`, `/en/privacy/`: privacy policy
- `/support/`, `/en/support/`: support
- `/`, `/en/`: landing page

This repository is public. It holds no personal details beyond the contact address on the
pages.
